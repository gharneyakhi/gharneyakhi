# فاکتور ساز

اپلیکیشن فارسی و راست‌به‌چپ برای ساخت فاکتور حرفه‌ای — برای هر کسب‌وکاری، با سربرگ کاملاً شخصی‌سازی‌شده و بک‌اند Supabase.

## امکانات

- **تنظیم فاکتور**: نام کسب‌وکار، شعار، شناسه ملی، کد اقتصادی، شماره ثبت، کد پستی، تلفن، همراه، ایمیل، وب‌سایت، نشانی و اطلاعات بانکی را یک‌بار وارد کنید.
- **بارگذاری لوگو**: فایل PNG، JPG، WEBP یا SVG تا ۳ مگابایت؛ در Supabase Storage به‌صورت خصوصی ذخیره می‌شود.
- **سربرگ خودکار**: هر فیلدی که در «تنظیم فاکتور» پر شود بالای فاکتور چاپ می‌شود. فیلدهای خالی چاپ نمی‌شوند.
- **سه خروجی از یک فاکتور**:
  - **پرینت** — چاپ مستقیم روی کاغذ A۴ از همین صفحه
  - **اکسل** — فایل `.xlsx` راست‌به‌چپ با سربرگ، جدول اقلام، جمع‌ها و مبلغ به حروف
  - **تصویر** — ذخیره فاکتور به‌صورت `JPG` با کیفیت دو برابر
- اقلام با واحد دلخواه (عدد، کیلوگرم، ساعت، جلسه، …)، تخفیف هر ردیف، تخفیف کل، مالیات بر ارزش افزوده و مبلغ پرداختی
- واحد پول تومان یا ریال، مبلغ نهایی به حروف فارسی، رنگ سربرگ دلخواه
- شماره‌گذاری خودکار فاکتور، وضعیت پیش‌نویس / صادر شده / پرداخت شده
- ذخیره فاکتورها و تنظیمات در حساب کاربری شما (ثبت‌نام با ایمیل یا ورود مهمان)
- Row Level Security: هر کاربر فقط فاکتورها و تنظیمات خودش را می‌بیند

## ساختار

```
src/
  App.jsx                     پوسته برنامه، مسیریابی و مدیریت خروجی‌ها
  components/
    InvoiceDocument.jsx       خودِ فاکتور (سربرگ، جدول، جمع‌ها) — منبع مشترک پیش‌نمایش، پرینت و JPG
    AuthScreen.jsx            ورود و ثبت‌نام
    ui.jsx                    اجزای مشترک فرم
  pages/
    DashboardPage.jsx         پیشخوان و آمار
    InvoiceEditorPage.jsx     ساخت و ویرایش فاکتور + پیش‌نمایش زنده
    InvoicesPage.jsx          فهرست فاکتورها
    InvoiceSettingsPage.jsx   «تنظیم فاکتور» و بارگذاری لوگو
  lib/
    invoice.js                مدل داده، محاسبه جمع/تخفیف/مالیات، فیلدهای سربرگ
    format.js                 ارقام فارسی، پول، تاریخ شمسی و مبلغ به حروف
    exports.js                پرینت، اکسل و JPG
    xlsx.js                   نویسندهٔ xlsx بدون وابستگی خارجی
  services/
    business.js               پروفایل کسب‌وکار + آپلود لوگو
    invoices.js               CRUD فاکتورها
```

### چرا `xlsx` دستی نوشته شده؟

بستهٔ `xlsx` روی npm یک هشدار امنیتی سطح بالا دارد که نسخهٔ رفع‌شدهٔ آن در registry منتشر نشده است. چون این پروژه فقط فایل اکسل **می‌نویسد** (هرگز فایل ورودی را تجزیه نمی‌کند)، `src/lib/xlsx.js` حداقلِ قالب OOXML را بدون هیچ وابستگی تولید می‌کند و `npm audit` تمیز می‌ماند.

## راه‌اندازی Supabase

1. یک پروژه در [Supabase](https://supabase.com) بسازید.
2. این دو migration را به ترتیب در **SQL Editor** اجرا کنید (یا با CLI دستور `supabase db push`):
   - `supabase/migrations/20260816000000_initial_backend.sql` — جدول `profiles` و trigger ساخت کاربر
   - `supabase/migrations/20260902000000_invoice_maker.sql` — جداول `business_profiles` و `invoices`، سیاست‌های RLS و bucket لوگو
3. در **Authentication → Providers → Anonymous Sign-Ins** ورود مهمان را فعال کنید.
4. فایل env محلی را بسازید:

```bash
cp .env.example .env
```

و مقادیر عمومی را از **Project Settings → API** وارد کنید:

```dotenv
SUPABASE_URL=https://YOUR_PROJECT_REF.supabase.co
SUPABASE_ANON_KEY=YOUR_PUBLIC_ANON_KEY
```

> فقط anon key عمومی را در فرانت‌اند/Vercel قرار دهید؛ هرگز `service_role` key را افشا نکنید.

## ساختار دیتابیس و امنیت

- `business_profiles` — یک ردیف برای هر کاربر؛ تمام فیلدهای سربرگ، مسیر لوگو، رنگ، واحد پول، درصد مالیات و متن‌های پیش‌فرض.
- `invoices` — اقلام و مشخصات خریدار به‌صورت `jsonb` تا برای هر صنفی قابل استفاده باشد؛ ستون‌های پولی از پیش محاسبه و ذخیره می‌شوند تا آمار پیشخوان با یک کوئری خوانده شود.
- bucket خصوصی `invoice-assets` — حداکثر ۳ مگابایت، فقط فرمت‌های تصویری. لوگو با signed URL و سپس data URL خوانده می‌شود تا در پرینت و خروجی JPG هم دقیقاً یکسان بماند.
- سیاست‌های RLS روی هر دو جدول و روی Storage: هر کاربر فقط پوشهٔ UUID خودش.

## اجرا

```bash
npm install
npm run dev
```

بررسی build:

```bash
npm run build
```

> تا زمانی که `.env` تنظیم نشده باشد، برنامه به‌جای صفحهٔ ورود، راهنمای اتصال Supabase را نشان می‌دهد.
