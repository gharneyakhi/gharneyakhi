# همسایه‌یار

یک رابط کاربری فارسی و راست‌به‌چپ برای ثبت محرمانه و پیگیری گزارش‌های مزاحمت همسایگی.

## امکانات

- داشبورد وضعیت گزارش‌ها و اعلان‌ها
- فرایند چندمرحله‌ای ثبت گزارش با امکان ثبت ناشناس
- دسته‌بندی مزاحمت‌ها، ثبت جزئیات، مدرک و شدت اتفاق
- جست‌وجو، فیلتر و مشاهده خط زمانی گزارش‌ها
- صفحات راهنمای همسایگی، پشتیبانی و تنظیمات حریم خصوصی
- ذخیره گزارش‌های ثبت‌شده در مرورگر
- طراحی واکنش‌گرا برای دسکتاپ و موبایل

## اجرا

```bash
npm install
npm run dev
```

برای ساخت نسخه نهایی:

```bash
npm run build
```
