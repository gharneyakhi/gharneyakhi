# DAVAM — گالری ساعت دوام

وب‌سایت حرفه‌ای و راست‌به‌چپ گالری ساعت **DAVAM** با طراحی لوکس، واکنش‌گرا و تجربه خرید تعاملی.

## امکانات

- صفحه اصلی کامل با هیرو، کالکشن‌ها، محصولات منتخب، داستان برند و خدمات
- فیلتر ساعت‌ها بر اساس مردانه، زنانه، اتوماتیک و یونیسکس
- جست‌وجوی سریع بین مدل‌ها و کالکشن‌ها
- نمایش سریع مشخصات محصول و انتخاب تعداد
- سبد خرید کشویی با مدیریت تعداد، جمع سفارش و نوار ارسال رایگان
- علاقه‌مندی‌ها، اعلان‌های تعاملی و فرم عضویت باشگاه مشتریان
- منوی موبایل و چیدمان کاملاً واکنش‌گرا
- تصاویر اختصاصی محصولات و رابط فارسی با پشتیبانی RTL
- رعایت حالت کاهش حرکت (`prefers-reduced-motion`) و اصول پایه دسترس‌پذیری

## اجرا

```bash
npm install
npm run dev
```

برای بررسی نسخه نهایی:

```bash
npm run build
npm run preview
```
