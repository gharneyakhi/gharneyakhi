# کارت ویزیت پت شاپ «میولند» 🐶

طراحی کارت ویزیت دو رو برای پت شاپ میولند — شهریار، خیابان ولیعصر، نبش کوچه احمد.

## خروجی‌ها

| فایل | توضیح |
| --- | --- |
| `print/miyoland-business-card.pdf` | **فایل آماده چاپ** — دو صفحه (جلو و پشت)، دقیقاً به سایز ۸۵٫۶ × ۵۴ میلی‌متر |
| `print/front.png` / `print/back.png` | تصویر هر رو با رزولوشن ۳۵۰ DPI (۱۱۷۸ × ۷۴۳ پیکسل) |
| `print/both-sides.jpg` | پیش‌نمایش کنار هم هر دو رو |
| `print/logo.png` / `svg/logo.svg` | لوگوی سگ (نسخه برداری + نسخه تصویری) |
| `svg/front.svg` / `svg/back.svg` | سورس برداری هر دو رو (قابل ویرایش) |
| `index.html` | صفحه نمایش‌دهنده با حالت چاپ (در مرورگر) |

## مشخصات طراحی

- **سایز:** استاندارد جهانی کارت ویزیت ۸۵٫۶ × ۵۴ میلی‌متر (A8)
- **رنگ‌ها:** سبز یاسی `#0C444D`، نارنجی `#EE9A3F`، کرم `#FBF3E2`
- **فونت:** وزیرمتن (Vazirmatn)
- **رزولوشن خروجی چاپ:** ۳۵۰ DPI

## بازتولید خروجی‌ها

```bash
npm install     # sharp و pdf-lib
node render.js  # تولید دوباره PNGها و PDF
python3 build_html.py  # به‌روزرسانی index.html پس از ویرایش SVG
```

> فونت‌های TTF برای رندر سرور باید در `~/.fonts` (یا `/usr/share/fonts`) نصب باشند.

## یادداشت برای چاپ

- طرح‌ها تا لبه کارت رنگ هستند؛ اگر چاپخانه نیاز به **بلید (bleed)** دارد، ۳ میلی‌متر به ابعاد هر طرف اضافه کنید و فایل SVG را با ابعاد بزرگ‌تر رندر بگیرید.
- برای چاپ حرفه‌ای، بهتر است فایل PDF را در چاپخانه از نظر پروفایل رنگی (CMYK) بررسی کنند.
